# ПРАВИЛА АГЕНТА (МОБИЛЬНЫЙ РЕЖИМ)
1. НИКОГДА не вставляй открытые URL (https://...) в команды терминала — телефонный браузер их обрезает. Все URL хранить только в Base64.
2. НИКОГДА не используй индексы [0] после переменных при вставке через буфер обмена без проверки (мобильный браузер съедает [0]). Используй next(iter(...)) или safe_run.py.
3. Полоска прогресса в терминале должна быть строго однострочной (не длиннее 18 символов): `\r[████░░░░░░] 40%`.
4. Графика: зафиксированные эталонные 3D-персонажи (с вырезанным фоном) поверх детализированных 2D-фонов + локальная озвучка piper-tts + Lip-Sync по амплитуде звука.
